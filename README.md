
# Увс аймгийн Улаангом хотын 2-р сургууль

Сургуулийн танилцуулга, арга хэмжээ, амжилт, архив, зураг бичлэг болон холбоо барих мэдээллийг нийтлэх вэбсайт.

## Ашигласан технологи
- HTML
- CSS
- JavaScript
- GitHub Pages

## Хавтасны бүтэц
- `index.html` — Нүүр хуудас
- `css/style.css` — Загвар, өнгө, байрлал
- `js/main.js` — Цэс болон JavaScript үйлдлүүд
- `pages/about.html` — Танилцуулга
- `pages/events.html` — Арга хэмжээ
- `pages/achievements.html` — Амжилт
- `pages/archive.html` — Архив
- `pages/gallery.html` — Зураг, бичлэг
- `pages/contact.html` — Холбоо барих

## Ажиллуулах
`index.html` файлыг браузераар нээнэ.

## GitHub Pages
GitHub репозиторын Settings → Pages хэсгээс:
1. Deploy from a branch сонгоно.
2. `main` салбар болон `/(root)` хавтсыг сонгоно.
3. Save дарна.

## Анхаарах зүйл
Нийтлэхийн өмнө жишээ мэдээллийг бодит мэдээллээр солино.
Сурагчдын зураг, нэр болон хувийн мэдээллийг нийтлэхдээ зөвшөөрөл авна.
