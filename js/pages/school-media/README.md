
# Увс аймгийн 2-р сургуулийн медиа сан

Сургуулийн зөвшөөрөлтэй зураг, медиа файлыг ангилан хадгалах repository.

## Хавтас
- images/school/ — сургуулийн ерөнхий зураг
- images/events/ — арга хэмжээний зураг
- images/achievements/ — амжилтын зураг
- videos/ — видео хостингийн холбоос, тэмдэглэл

## Зураг ашиглах
GitHub Pages-ийг идэвхжүүлсний дараа бодит URL-аа ашиглан:

<img
  src="https://YOUR-USERNAME.github.io/school-media/images/school/example.jpg"
  alt="Сургуулийн зураг"
>

YOUR-USERNAME болон repository-ийн нэрийг
өөрийн GitHub тохиргоотой тааруулна.

## Видео
Том хэмжээний видеог GitHub-д хадгалахын оронд
YouTube зэрэг тохиромжтой видео хостинг ашиглана.

## Нууцлал
Нийтэд нээлттэй зураг, файлыг бусад хүн үзэж,
хуулж авч болно. Сурагчдын зураг, нэрийг нийтлэхдээ
сургуулийн зөвшөөрөл болон хүүхдийн нууцлалыг анхаарна.
